# effect-atom-jsx (deprecated)

`effect-atom-jsx` is now **Affe**, published as
[`@doeixd/affe`](https://www.npmjs.com/package/@doeixd/affe). This package
only re-exports `@doeixd/affe` so existing imports keep working during the
transition window.

This directory is generated by `scripts/generate-effect-atom-jsx-alias.mjs`
from the core `exports` map; regenerate it rather than editing it. Publish it
after `@doeixd/affe` itself is published.

Migrate by replacing the package name everywhere it appears:

```sh
npm uninstall effect-atom-jsx
npm install @doeixd/affe
```

- `import { Atom } from "effect-atom-jsx"` → `import { Atom } from "@doeixd/affe"`
- `effect-atom-jsx/<subpath>` → `@doeixd/affe/<subpath>`
- `"jsxImportSource": "effect-atom-jsx"` → `"jsxImportSource": "@doeixd/affe"`
- Babel `moduleName: "effect-atom-jsx/runtime"` → `moduleName: "@doeixd/affe/runtime"`

Runtime brand keys and symbol keys moved from `effect-atom-jsx/...` to
`affe/...`, so values dehydrated by an `effect-atom-jsx` release are not read
by `@doeixd/affe`.
