# @doeixd/create-affe

Create an [Affe](https://github.com/doeixd/affe) app:

```sh
npm create @doeixd/affe@latest my-app
cd my-app
npm install
npm run dev
```

You get Vite with `@doeixd/affe/vite`, strict TypeScript, a counter built on
atoms, and a slot-contract component with a style and a behavior attached from
outside.

Add a component to an existing project:

```sh
npm create @doeixd/affe@latest -- --component SearchBox src/components
```
